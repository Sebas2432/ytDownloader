# ytDownloader

Simple rust program to download YouTube videos into mp4 files using a url.

## How to run
Run
```
git clone git@github.com:Sebas2432/ytDownloader.git
cd ytDownloader
cargo run
```

After downloading all the dependencies, enter any url, and it will start downloading. \
Currently only supports single videos, no playlists, etc. \
For full Limitations visit: \
https://github.com/4thel00z/ytdown

The video will be downloaded into the cloned directory, as "out.mp4". Currently, you need to move the downloaded video or move it, otherwise it will be overwritten.
